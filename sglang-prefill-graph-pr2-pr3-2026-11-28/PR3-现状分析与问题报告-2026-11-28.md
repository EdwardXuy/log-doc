## 2. A3 DSV4：QLI metadata 2048 vs 1024（B060 仍未修）

日志：https://github.com/sgl-project/sglang/actions/runs/46096195872/job/140828789662

```
RuntimeError: call aclnnQuantLightningIndexerV2 failed, detail:[PID: ...]
Invalid_Argument_Tensor_Shape_Size(EZ0015):
Parameter metadata of QuantLightningIndexerV2 has incorrect shape size 2048.
Reason: The shape size of metadata must be 1024.
```

与 B050 完全一致。PR2 侧同样复现（B050/B060、deepep/ascend_ops、带/不带 2048 桶都复现），
说明是 A3 侧 DSV4 captured metadata 的分配/ABI 问题，不是镜像或测试参数问题。

详细的代码定位与修复建议见 PR2 报告 §3：

- `Dsv4PrefillGraphMetadata.allocate` 用所有 `kernel_metadata` 的最大 numel 统一分配；
- A3 的 `win/c4a/c128a` 固定 2048，把必须为 1024 的 `li_quant_metadata` 也分成了 2048；
- 建议 `li_quant_metadata` 固定 1024，或按 key 单独分配。

## 3. A5 DSV4：`dflash_info_v2.py:241 NameError`

日志：https://github.com/sgl-project/sglang/actions/runs/46096195872/job/140828789572

```
File "/sgl-workspace/sglang/python/sglang/srt/speculative/dflash_info_v2.py", line 241, in prepare_for_decode
    if num_needed_tokens > 0:
NameError: name 'num_needed_tokens' is not defined. Did you mean: 'num_new_tokens'?
```

分析：

- 这是 server 侧代码 bug，与测试参数无关；
- 发生在 A5 文件的 `TestNPUDeepSeekV4FlashDSPARK`（perf class）setUpClass，导致整个文件 exit code 5；
- 同一文件里的 `TestNPUDeepSeekV4FlashFP84PGPQA`（accuracy class）因此**没有执行**；
- 同一 A5 suite 里的 Qwen3.6 用例 PASS。

→ A5 的 GPQA accuracy 目前**不能算已验证**，需要先修 `dflash_info_v2.py` 的 NameError，再单独跑 accuracy class。

## 4. GLM5.3：ascend_ops allgather 行数不匹配

日志：https://github.com/sgl-project/sglang/actions/runs/46096195872/job/140828789539

```
ValueError: Ascend AllGather rank 10 has 256 rows, expected 1024
Fail when using backend: breakable for prefill runner.
```

分析：

- capture 时按 bucket 1024 发布了 `ascend_allgather_row_sizes`；
- replay 时 GPQA 短 prompt 的实际行数只有 256，与 capture 的 1024 不一致；
- 说明 ascend_ops allgather 的 replay 要求 live rows 等于 capture bucket（或需要 DP padding），
  短 prompt/多请求场景没有回退 eager，直接报错；
- GLM 使用 `--attention-backend ascend`（非 DSV4）、NEXTN、2 节点 TP32，也不在
  PR #49481 的验证矩阵里。

→ GLM 目前不适合用 GPQA 短 prompt 跑 BCG；需要开发支持 padding/fallback，或在 PR1 中标记 known limitation。
